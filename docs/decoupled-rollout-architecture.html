Key Problems to Solve

1. Weight Transfer Latency

140 GB at 100 Gbps = ~11s. At 10 Gbps (cross-DC) = ~2 min. Must not stall the training loop. Delta compression + async streaming needed.

2. Replace ExternalRayDistributedExecutor

Current executor does ray.get_actor() on local cluster. Need a remote weight-loading protocol that hot-swaps weights into a running vLLM instance.

3. On-Policy Staleness

RL requires fresh weights. 2-4 steps of lag tolerable, beyond that up to 75% performance collapse (INTELLECT-2 ablations). Must track and bound staleness.

4. Multi-Turn Fault Tolerance

Agentic episodes run 10-50 turns over minutes. If a rollout worker dies mid-episode, the entire episode is lost. Need checkpointing or recovery.

5. TEE Deployment on Cloud

H100 CC-On available on GCloud + Azure. Near-zero overhead confirmed. Must set up Confidential VMs, attestation flow, and encrypted weight delivery pipeline.

6. Non-TEE Protection (Community GPUs)

Consumer GPUs lack TEE. Advisor-style split (open draft model on worker, proprietary verifier on trusted side) or MoE expert distribution needed for broader participation.
